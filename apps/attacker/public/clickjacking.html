Clickjacking Demo

これは CSRF ではなく、
本物の Shop 画面を押させるデモです

このページ自身は /purchase に直接 POST しません。背後に埋め込んだ /purchase/1 の本物の「購入する」を、被害者のクリックで押させます。

限定キャンペーン

表向きはプレゼント応募ページに見せていますが、実際のクリック先は埋め込まれた Shop の購入ボタンです。

景品を受け取る
いま見えている大きなボタンの位置に、Shop の本物の「購入する」が重なっています。

CSRF との違い

CSRF 攻撃者ページが被害者ブラウザから勝手にリクエストを送ります。被害者は正規サイトの画面を押していません。
Clickjacking 攻撃者ページが正規サイトを iframe で埋め込み、被害者自身に本物の UI を押させます。
  1. Shop で alice / password123 でログインする
  2. まずは「本物の Shop 画面を表示する」を押して、背後に /purchase/1 があることを見る
  3. 「隠してもう一度試す」で元に戻す
  4. 大きな「景品を受け取る」位置をクリックする
  5. Shop の /orders で注文が増えていることを確認する
